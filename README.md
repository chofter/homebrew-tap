# Chofter tap

Homebrew casks for [Chofter Apps](https://www.chofter.com).

```sh
brew tap chofter/tap
brew trust chofter/tap
brew install --cask disk-space
brew install --cask agent-graph
```

Homebrew will not load a cask from a tap outside its own repositories until you
say you trust it, which is what the second line is for. It is asking whether you
trust this repository to run code on your machine; the answer is yours to give.

## Disk Space

A disk usage analyser for macOS: scan a folder or a whole drive, see where the
space went, and act on it. Results appear while the scan runs rather than after
it. [diskspace.io](https://www.diskspace.io/)

Requires macOS 15 or later. Signed and notarised, so it opens without a warning.

Updating it: `brew update && brew upgrade --cask disk-space`. To remove it along
with the scan history, logs and settings it keeps: `brew uninstall --zap --cask
disk-space`.

## Agent Graph

A command-line tool that records, watches and shares a live graph of your AI
coding agents: which session started which agents, who's waiting on whom, what
looks stuck, and what needs you.
[agentgraph.chofter.com](https://agentgraph.chofter.com)

For macOS and Linux, on ARM and Intel. The macOS programs are signed and
notarised, so they run without a warning. Once it's installed, start recording
Claude Code sessions with `agent-graph install claude-code`.

Updating it: `brew update && brew upgrade --cask agent-graph`. To remove it,
first take its hooks out of Claude Code with `agent-graph uninstall
claude-code`, then `brew uninstall --cask agent-graph`. What it recorded stays
in `~/.agent-graph`; delete that folder too if you don't want it.

It's a cask rather than a formula because it's a prebuilt program: Homebrew
checks that a formula without a bottle could be built from source, and refuses
it when the Command Line Tools are out of date, though nothing is built.

## How this is maintained

`Casks/disk-space.rb` is generated by the release build in the
[diskspace repository](https://github.com/shaneosullivan/diskspace) — its
version and checksum come from the disk image that was actually notarised, so
they cannot drift from what people download.

`Casks/agent-graph.rb` is written by `scripts/release.sh` in the
[agent-graph repository](https://github.com/shaneosullivan/agent-graph), from
the archives that release uploaded and checked (the macOS programs in them
notarised), so its versions and checksums are those of what people download.
